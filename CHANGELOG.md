# Changelog

All notable changes to `adarearch-laravel-sms` will be documented in this file.

## [1.0.0] - 2026-01-28

### Added
- Initial release
- Send single SMS
- Send bulk SMS (up to 400 recipients)
- Check message delivery status (DLR)
- Check account balance
- Automatic token management and refresh
- Token caching for performance
- Fluent API interface for easy usage
- Automatic MSISDN formatting
- Unicode content detection
- Promotional message time validation (9 AM - 8 PM)
- Comprehensive error handling with error codes
- Laravel facade support
- Service provider auto-discovery
- Configuration file publishing
- Example controller with common use cases
- Full documentation and README
